Embedding the slicer in your own web app

Three Slicer is published to npm as three-slicer: a WebAssembly slicing kernel that runs headless in Node or the browser, with an optional React viewer and a settings panel on top. These demos are separate applications built against the published package, each embedded here in an iframe, so what they show is the package's own surface rather than this site's wiring.

  • Instant quote — a customer drops in a model and the page slices it to get filament usage and print time, then prices the job from those numbers. No server round trip.
  • Printer showcase — the same model sliced against several machine profiles, comparing print time and material use per printer.
  • CAD embed — a design page that slices the model it is already showing, reusing the viewer component inside an existing 3D interface.

The engine is AGPL-3.0-or-later and the source, including these examples, is on GitHub. You can also use the slicer directly or read what it does.
